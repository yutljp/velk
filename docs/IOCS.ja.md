# インジケーター抽出

`velk --iocs FILE` は、印字可能な静的文字列と、制限付きエミュレーションで復元した文字列からインジケーターを抽出します。結果は種類ごとにまとめて表示します。`--json` を付けると、`kind`、`value`、`sources`、`references` の安定したフィールドを持つ JSON 配列を出力します。同じ種類と値は統合し、情報源と参照位置を保持します。各参照には関数と命令またはブロックのアドレスが含まれます。

スクリプト API では `binary.iocs()` から同じ結果を取得できます。`--run`、`--mcp`、`--serve` で実行するスクリプトでも利用できます。情報源には `staticString`、`decodedString`、`staticConstant` があります。ネットワーク通信やレピュテーション照会は行いません。

HTTP、HTTPS、FTP、WebSocket、セキュア WebSocket の URL、同梱の保守的な TLD リストに含まれる末尾ラベルを持つドメイン、IPv4 と IPv6、メールアドレス、Windows パス、POSIX パス、`HKLM\\` または `HKEY_` で始まるレジストリパス、`Mozilla/` で始まるユーザーエージェントを認識します。制限付きエミュレーションで `CreateMutex`、`OpenMutex`、`CreateEvent`、`InternetOpen`、`WinHttpOpen` の引数として文字列が復元された場合は、API に応じた種類も記録します。暗号定数名は既存の定数シグネチャ検出機能から取得します。ドット区切りの数値は、前後の空白を除いた値全体が IP アドレスとして解析できる場合に限り IP として扱います。そのため `v1.2.3.4` のようなバージョン表記は IP として扱いません。この保守的な規則により、文章中に埋め込まれた値を見落とす場合があります。静的文字列は、エミュレーションで API 呼び出しの引数として復元できない限り、その API と関連付けません。
