# 構造体の復元

[English](STRUCTURES.md)

デバッグ情報がなくても、固定オフセットとアクセス幅からメモリアクセスのビューを復元できます。
添字付きアクセスやポインタの更新幅から、アクセスのストライドを求めます。
ストライドだけでは、ソースの配列要素サイズは確定しません。
ポインタの直接コピー、呼び出し、戻り値、共通の静的アドレスを通して、関数間でレイアウトを共有します。
接続された二つの関数が、添字付きの単一フィールドを含め、それぞれ異なるフィールドの根拠を提供できます。
幅、重なり、アラインメント、ストライドが矛盾する場合は共有しません。
呼び出し先が不明な間接呼び出しでは、レイアウトを接続しません。

復元したフィールドはメモリアクセスを表し、ソースのフィールド宣言や符号とは限りません。
重なるアクセスが一つの整列した領域に収まる場合、共用体のビューとして出力できますが、
ソースが共用体を宣言していたことを意味しません。
未使用フィールド、入れ子になったソースの型、観測されない末尾のバイトは推定しません。
生成するメンバは、ロードが明示的に符号拡張する場合を除き、符号なし整数の記憶領域を使います。
これはアクセス用の型であり、ソースの宣言を示しません。
ループ内で要素の途中を指すポインタは、生成した要素の先頭を基準に表し、対応するロードとストアをフィールド構文で出力します。
レジスタの部分読み出し、部分書き込み、定義前に読み出されるローカル値がある場合、この変換は行いません。
生成するフィールドには、`f_c` のように 16 進数のバイトオフセットを使う短い名前を付けます。
生成する構造体タグは、ソースのクラス名を推測せず、アクセスのレイアウト全体とストライドを表します。
同じ宣言は C の共通定義部分で共有し、異なる部分レイアウトには別のタグを使います。
現在のポインタレイアウトの復元は、64 ビットのレジスタ値を使います。

推定した構造体がある場合、CLI の `--card` と JavaScript の `f.card()` は
`structureLayouts` を含みます。MCP では `velk_run_script` から同じデータを取得できます。
各レイアウトは次の項目を持ちます。

- `name`: 生成した C の構造体タグ。
- `elementSize`: 観測した配列ストライドのバイト数。不明な場合は `null`。
- `minimumSize`: 最後に観測したフィールドの終端までのバイト数。末尾パディングは含みません。
- `fields`: 16 進数のバイトオフセット `offset`、C の `type`、バイト幅 `size` を持つアクセスのビュー。
- `sourceFields`: ソースで宣言されたメンバ。現在、推定レイアウトでは `null`。
- `sourceSize`: ソースで宣言されたサイズ。現在、推定レイアウトでは `null`。

`structures` には引き続き C の宣言が入ります。デバッグ情報の宣言は、これらの推定レイアウトとは別です。

```sh
velk --card tests/fixtures/metrics/struct_arrays.x86_64.O2.stripped.elf 0x201180
```

```js
const b = velk.open("tests/fixtures/metrics/struct_arrays.x86_64.O2.stripped.elf");
JSON.stringify(b.getFunction("0x201180").card().structureLayouts)
```

`tests/metrics.rs` は、構造体の stripped fixture を対応する DWARF fixture と比較します。
`tests/golden/structure_accuracy.txt` に、構成ごとのフィールドのオフセット、幅、型、配列要素サイズについて、
正解、誤り、未復元の数を記録します。構造体ポインタ引数の直接メンバのうち、ビットフィールド以外を対象とします。
入れ子の集約型は展開せず、ソースの共用体と値渡しの集約型は採点しません。
レイアウトやストライドが不明な場合は未復元、余分なフィールドは誤りと数えます。
アクセス幅が正しくても、符号の違いは型の誤りと数えます。

アクセスとソースの比較は残し、相違がある関数とオフセットをすべて記録します。
生成した記憶領域の型を変えても、ソースの型が確定したことにはなりません。
別のソース用の指標では `sourceFields` と `sourceSize` だけを採点し、
不明な宣言は正解ではなく未復元と数えます。
